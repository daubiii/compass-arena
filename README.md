# Compass Arena — сайт организации

Статический сайт турнира по Dota 2: сетка, расписание, участники, регламент и архив турниров.
Хостинг — Netlify (папка публикации `"."`), состояние турнира — Netlify Functions + KV.

## Структура

```
index.html            главная: первый экран, сетка, участники, расписание, архив, следующий сезон
schedule.html         расписание: фильтры, группировка по дням, .ics и VOD
history.html          архив организации: главы турниров, чемпионы, MVP, галерея
rules.html            регламент
404.html              страница «не найдено»
site.css              дизайн-система и общие компоненты (единственный общий CSS)
assets/
  ca-data.js          данные: загрузка /api/data, нормализация, связи сетки, фазы, статистика
  ca-ui.js            UI-кит: спрайт иконок, «хром», диалоги, тосты, reveal, прогресс
  ca-views.js         общие куски интерфейса: строка матча, выбывшие, баннер чемпиона, карточка сезона
  ca-bracket.js       компонент турнирной сетки (CSS Grid + SVG-линии)
  ca-home.js          контроллер главной
  ca-schedule.js      контроллер расписания
  ca-history.js       контроллер архива
  ca-rules.js         контроллер регламента
functions/api/
  data.js             GET  /api/data — отдаёт состояние турнира + history
  save.js             POST /api/save — сохранение из админки (пароль ADMIN_PASSWORD)
poasalj1.z23.html     админка (не индексируется, закрыта в robots.txt)
tests/                локальные проверки (см. ниже)
```

Все страницы — ванильный HTML/CSS/JS без сборки. Логики в inline-скриптах нет: страница подключает
`assets/ca-*.js` с `defer`, каждый скрипт вешает свой `CA.<page>.init` на `DOMContentLoaded`.

## Состояния турнира

`CA.data.finalize()` считает фазу один раз для всех страниц и проставляет `body[data-phase]`:

| фаза   | когда                                         | что показывает главная                                              |
|--------|-----------------------------------------------|---------------------------------------------------------------------|
| `pre`  | нет победителя финала, старт в будущем        | отсчёт до старта, набор команд, сетка с участниками                  |
| `live` | есть `liveMatchId` или прошла дата старта      | следующий матч с таймером, ленивый плеер, live-акценты (кровь)       |
| `post` | у матча M5 есть победитель                     | баннер чемпиона, итоги, архив и блок «следующий сезон»               |

Дата-заглушка (`START_FALLBACK` в `ca-data.js`) сама по себе не включает `live` — только дата,
пришедшая с сервера. Это защищает сайт от «ожившего» эфира, если в админке забыли дату.

Матч имеет состояние `done` / `live` / `upcoming` / `tbd`; цвета и подписи заданы классами
`.match.is-done`, `.is-live`, `.is-next`, `.st-done`, `.st-live`, `.st-next` в `site.css`.

## Дизайн-система

- Токены в `:root` (`site.css`): поверхности `--bg/--raise/--card`, текст `--text/--text-2/--text-3`,
  акценты `--gold/--gold-hi` и `--blood/--blood-hi`, радиусы, `--ease`.
- Мотив: компас (`#i-compass`, класс `.arena-compass`), сетка арены (`.arena`), зерно поверх фона
  (`body::before`), орнамент-разделитель (`.orn`).
- Иконки: спрайт в `assets/ca-ui.js`. В разметке — `<svg class="ic"><use href="#i-trophy"></use></svg>`,
  в JS — `CA.ui.icon('trophy', 'ic-20')`. Чтобы добавить иконку, допишите `<symbol id="i-имя">` в `SPRITE`.
- Кнопки: `.btn` + `.btn-gold` / `.btn-ghost` / `.btn-live` / `.btn-quiet`, размеры `.btn-sm/.btn-lg`.
- Статусы: `.st` + `.st-live/.st-next/.st-done/.st-gold/.st-flag`, живая точка — `.dot-live`.

## Данные и админка

`CA.data.load()` тянет `/api/data` (ответ: `tournament`, `teams`, `matches`, `schedule`, `liveMatchId`,
`tournamentStart`, `projectStart`, `nextSeason`, `history`), нормализует и рассылает подписчикам.
Обновление — раз в 60 секунд (`startAutoRefresh`).

Поля, которые нужны публичной части:

- `matches[].vod` — ссылка на запись матча (кнопка VOD в сетке и расписании);
- `nextSeason` — `{ name, date, url, note }` — блок «следующий сезон» после финала;
- `history[]` — зафиксированные турниры с `championId`, `mvp`, `photos`.

В админке (`poasalj1.z23.html`) для них есть поля: «🚀 Следующий сезон» в настройках и «🎬 VOD»
в карточке каждого матча.

## Локальный запуск и проверки

```powershell
# сайт с моковым /api/data (post-состояние по умолчанию)
node tests/server.mjs                       # http://127.0.0.1:4173/
$env:CA_FIXTURE='pre';  node tests/server.mjs   # до старта
$env:CA_FIXTURE='live'; node tests/server.mjs   # эфир

# синтаксис
Get-ChildItem assets\*.js | ForEach-Object { node --check $_.FullName }

# проверки в jsdom (один раз: npm install — это только devDependency jsdom)
npm test                 # audit + smoke + smoke-history
node tests/smoke.mjs     # рендер главной/расписания/архива/правил/404 в трёх фазах
node tests/audit.mjs     # баланс CSS, ссылки на id, локальные ссылки, отсутствие inline-скриптов
```

`tests/fixtures.mjs` — тестовые данные, повторяющие формат админки; используйте их для новых проверок.
Самому сайту node_modules не нужны: это статические файлы, они публикуются как есть.

## Что осталось на потом

- `config.json`, `logo.png`, `gt.png` в корне не используются сайтом — это исходники/артефакты.
- `alwaysShowBracketBanner` в админке больше не влияет на главную (старый баннер убран).
- Визуальная проверка в реальном браузере в этой среде недоступна (headless Chrome не запускается
  в песочнице) — вёрстка проверена структурно в jsdom и чтением CSS. Стоит пройтись глазами
  по https://compassarena.ru/ после деплоя.
